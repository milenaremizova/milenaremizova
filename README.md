# Frontend Developer

Создаю веб-приложения и развиваюсь в направлении разработки интерфейсов и клиентской логики.

Уделяю внимание структуре, читаемости и поддерживаемости решений, а также устройству системы от пользовательского взаимодействия до архитектуры решений. Мне нравится не только создавать новое, но и разбираться в уже существующих решениях, чтобы лучше понимать их устройство и находить идеи для улучшений.
